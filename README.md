# Sweet Homes Real Estate

Three responsive visual concepts for the Sweet Homes Real Estate rental website.

- [Warm editorial concept](mockup-1.html)
- [Bright and bold concept](mockup-2.html)
- [Quietly refined concept](mockup-3.html)

Each page uses the same demo listings, renter review excerpts, and interactive visit shortlist. The WhatsApp button opens a prefilled draft; the visitor chooses the recipient and sends it. Property names, rents, and availability are sample content and must be replaced with verified inventory before launch.

## GitHub Pages

The site is static HTML, CSS, and JavaScript. The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages on pushes to `main`.
